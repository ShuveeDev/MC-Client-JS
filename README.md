## ⚡ Як встановити?  

### 🔧 Ручне встановлення (Linux):  
1️⃣ Створіть папку:  
```bash
mkdir mcbotjs && cd mcbotjs
```  
2️⃣ Клонуйте репозиторій:  
```bash
git clone https://github.com/ShuveeDev/MC-Client-JS .
```  
3️⃣ Встановіть залежності:  
```bash
npm i
```  
4️⃣ Запустіть бота:  
```bash
node index
```  

---

### 🚀 Швидке встановлення однією командою:  
```bash
mkdir mcbotjs && cd mcbotjs && git clone https://github.com/ShuveeDev/MC-Client-JS . && npm i && node index.js
```
